# Projet GraphMaster

## Installation et exécution

1. Cloner le projet :
   git clone https://github.com/ranim125/projet_graphes

2. Aller dans le dossier front :
   cd projet_graphes/front

3. Installer les dépendances :
   npm install

4. Lancer l’application :
   npm start

L’application sera accessible sur :
http://localhost:3000
